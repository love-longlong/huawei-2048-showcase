# 2048 · 云端小游戏

使用华为云 AI 开发者空间协助开发、检查和整理的单文件网页游戏。

## 功能

- 4×4 棋盘，合并相同数字，尝试得到 2048。
- 键盘方向键、WASD 与手机触屏滑动。
- 当前分数、浏览器本地最高分、重新开始。
- 胜利提示、继续游戏及无法移动时的结束提示。

## 运行

直接用现代浏览器打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8080
```

浏览器访问 http://127.0.0.1:8080/ 。页面为纯静态应用，不需要后端、数据库、账号或 API 密钥。

## 实现

HTML 构建界面，CSS Grid 布局，原生 JavaScript 保存棋盘并处理移动、合并和计分。最高分通过当前浏览器的 localStorage 保存，不上传到服务器。

```mermaid
flowchart LR
  A[键盘或触屏] --> B[方向归一化]
  B --> C[压缩与单次合并]
  C --> D[还原棋盘方向]
  D --> E[生成新方块]
  E --> F[计分与胜负检测]
  F --> G[更新页面]
```

## 检查记录

已在 AI 开发者空间用 jsdom 检查初始化、键盘事件、触屏事件、分数与重开逻辑；检查并修正了上下方向映射及游戏结束提示的优先级。模拟 DOM 检查不能代替所有浏览器和手机上的手工测试。
